Getting Started

Three ways to use winky-wonky. Pick whichever fits your stack — they all work.

1 Add the script + CSS

Drop these two tags in your <head>. That's it. No build step, no npm, no framework.

<!-- CSS --> <link rel="stylesheet" href="https://unpkg.com/winky-wonky/dist/winky-wonky.css"> <!-- JS (global WinkyWonky) --> <script src="https://unpkg.com/winky-wonky/dist/winky-wonky.min.js"></script>

2 Use any component

All 25 components are available on the global WinkyWonky object.

<div id="app"></div> <script> const { createRippleButton, createTiltSlider, AudioSynth } = WinkyWonky; AudioSynth.setVolume(0.15); const btn = createRippleButton({ label: 'Click me', onClick: () => console.log('pressed') }); document.getElementById('app').appendChild(btn.el); </script>

1 Install

Works with any bundler — Vite, webpack, Rollup, esbuild. Vanilla JS, zero dependencies.

npm install winky-wonky

2 Import CSS + components

Import the stylesheet once in your app entry. Then use any component anywhere.

// app.js — import once at root import 'winky-wonky/style.css'; import { createTiltSlider, AudioSynth } from 'winky-wonky'; const slider = createTiltSlider({ initialValue: 50, gravity: 0.4, onChange: (v) => console.log('value:', v) }); document.body.appendChild(slider.el);

3 React? Use the wrapper

If you're in React, install the wrapper for drop-in components.

npm install winky-wonky winky-wonky-react
// App.jsx import 'winky-wonky/style.css'; import { TiltSlider, WobblyCheckbox, RippleButton } from 'winky-wonky-react'; function App() { return ( <> <TiltSlider initialValue={50} /> <WobblyCheckbox labelText="Enable physics" /> <RippleButton label="Submit" /> </> ); }

1 Copy a single component

Don't want a dependency? Copy the source. Every component is a single self-contained JS file with zero imports except audioSynth.js and utils.js. Grab what you need.

// Copy these 3 files from src/components/: // 1. utils.js — shared helpers (reduced-motion, ARIA, pointer drag) // 2. audioSynth.js — Web Audio synthesis (optional, can remove) // 3. rippleButton.js — the component you want // Then import and use: import { createRippleButton } from './components/rippleButton.js'; const btn = createRippleButton({ label: 'Go' }); document.body.appendChild(btn.el);

2 Or grab from GitHub

Every component lives in src/components/. Each file is under 250 lines. The CSS lives in src/winky-wonky.css (the aggregate) and src/styles/ (one file per component) — grab the file for the component you want.

# Clone the repo and copy what you need git clone https://github.com/harshmathurx/winky-wonky.git # Components are in: # src/components/rippleButton.js # src/components/tiltSlider.js # src/components/wobblyCheckbox.js # ... (25 total) # CSS for each component is clearly labeled in: # src/winky-wonky.css (aggregate — imports src/styles/*.css)

Dynamic: TypewriterInput, BalloonTooltip, HingeDropdown, SlinkyAccordion, DrunkLoader, SuspiciousEyes
Gothic: SlimeProgress, RatingStars, GrumpyModal, RotaryColorPicker
System: WobblyRadioGroup, SpringyTabs, GravityToast, WobblySwitch, RippleButton, MagneticNav, ElasticDragList
